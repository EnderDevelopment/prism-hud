# Minecraft Client HUD Mod

PrismHUD is a client-side Fabric Minecraft HUD mod that displays live FPS, server ping, Java memory usage, player coordinates, facing direction, in-game time, biome, block light level, and dimension in a compact overlay.

## Install

1. Install Fabric Loader 0.16.5 or newer for Minecraft 1.21.1.
2. Install Fabric API for Minecraft 1.21.1.
3. Build the project with `./gradlew build` on Linux or macOS, or `gradlew.bat build` on Windows.
4. Copy the generated `build/libs/statushud-1.0.0.jar` file into your Minecraft `.minecraft/mods` folder.
5. Launch Minecraft using your Fabric profile.

## Use

1. Enter a world or join a server to view the HUD in the top-left corner.
2. Press F8 to show or hide the HUD. You can change the key in Minecraft’s Controls menu.
